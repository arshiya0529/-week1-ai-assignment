## 🐍 Part 2: Smart Student Assistant (`main.py`)

A Python-based interactive assistant with 3 features:

| Feature | Description |
|---|---|
| 📚 Study Tips | Randomly picks 3 tips from tips.json |
| ✨ Motivation Quote | Displays a random motivational quote |
| 🕐 Date & Time | Shows current date and time |

**How to Run:**
```bash
python main.py
```

**Requirements:** Python 3.x (no external libraries needed)

## 🌐 Part 3: API & JSON Task (`api_task.py`)

Fetches live joke data from [JokeAPI](https://v2.jokeapi.dev) — free, no API key required.

- Parses JSON response
- Displays formatted output
- Saves result to `api_output.txt`

**How to Run:**
```bash
pip install requests
python api_task.py
```
